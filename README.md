# Perfil de Viagens

Landing page desenvolvida durante a trilha de Fullstack da Rocketseat, simulando o perfil de uma usuária em uma rede social de viagens (estilo Instagram/Travelgram).

## 🔍 Sobre o projeto

O objetivo é praticar HTML semântico e CSS puro na construção de uma página de perfil, trabalhando com:

- Estruturação semântica (`header`, `nav`, `main`, `article`, `section`, `footer`)
- Estilização com variáveis CSS (`:root`)
- Flexbox para layout (navbar, cabeçalho de perfil e grid de fotos)
- Tipografia customizada com Google Fonts (Poppins)
- Aninhamento de seletores em CSS puro

## 🚀 Tecnologias

- HTML5
- CSS3

## 📁 Estrutura do projeto

```
perfil-de-viagens/
├── assets/
│   ├── icons/       # Ícones utilizados na página
│   ├── images/      # Fotos exibidas na galeria
│   └── Logo.svg
├── style/
│   ├── global.css   # Variáveis globais e reset
│   └── style.css     # Estilos da página
└── index.html        # Estrutura principal da página
```

## ▶️ Como executar

Basta abrir o arquivo `index.html` em um navegador de sua preferência.
